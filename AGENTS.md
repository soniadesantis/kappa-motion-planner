# AGENTS.md (root)

## General Rules
- Do not change existing code in /src without asking
- Prefer minimal dependencies
- Better to write clear code rather than concise
- Do not modify the structure of the folder /src without asking permission
- Do not add files to /src without asking permission

## Protected paths
- `src/` is protected.
- Never modify `src/` without first asking the user for permission in that turn.
- If a request would touch `src/`, stop and ask before taking any action.
